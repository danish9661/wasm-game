# Starfall — Complex Structure Metrics

Generated by `scripts/blender/gen_complex.py` (see `docs/ART_DIRECTION.md` for the
shared style contract). All figures are measured from the **exported GLB files**,
not from the source scene.

## Conventions

- **1 tile = 1.0 unit.** Ground plane at `z = 0`.
- glTF export is **Y-up**: Blender `(x, y, z)` → glTF `(x, z, -y)`.
- Every model's **base sits exactly at glTF `y = 0`** and is **centred on glTF
  `(x, z) = (0, 0)`** (verified per vertex, tolerance < 1e-4).
- Footprint is measured in glTF **X × Z**; height is the glTF **Y** extent.
- **Player model = 1.55 u tall** — the ratio column is `height / 1.55`.
- Nominal storey height ≈ **2.5 u**; doors where present are **0.9 × 2.0 u**.
- Flat shading only, palette materials only (Principled BSDF, roughness 0.85,
  metallic only on steel/gold/iron), no textures, no smooth normals.
- Every asset is a multi-part assembly of 26–53 primitives; all stay well under
  the 1000-triangle complex-structure budget.

## Summary

- **12 assets**, **6,918 triangles total**; per-asset range **366–806** (budget: < 1000).
- **Tallest:** `watchtower_large` (8.13 u ≈ 5.25 players), then `wizard_tower` (8.02 u) and `castle_keep` (7.70 u).
- **Widest:** `bridge` (6.66 u span), then `temple` (5.74 u) and `town_hall` (5.20 u).
- **Smallest:** `market_stall` (2.96 u ≈ 1.9 players — still taller than the player).
- All large structures fall in the intended **4–8 u height / 3–6 u footprint** band; the bridge is a deliberately long, low span and the stall is a deliberately compact prop.
