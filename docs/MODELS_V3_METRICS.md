# Starfall - Model wave 3 metrics

Generated by `python3 scripts/build_models_v3_metrics.py` from `assets/models/expansion_models_v3.json`, the per-asset measurements written by `scripts/blender/gen_models_v3.py` after each GLB export. Numbers are cross-checked against `assets/models/metrics.json`.

## Scale contract

- **1 unit = 1 tile = 1 metre.** Blender is Z-up; exported glTF is Y-up. The tables give **W x D x H** in glTF axes (X footprint x Z footprint x Y height).
- Player reference: **1.55 u** (`player.glb` measures 1.55 u). Every ratio is `measured height / 1.55`.
- Storey height **2.5 u**; doors **0.9 x 2.0 u**; windows **0.8 x 0.9 u** raised to a **1.1 u** sill; grid pitch **1 u**; street lamp **3.0 u** (`street_lamp` measures 3.06 u).
- Every asset's lowest point is exactly **y = 0** and its footprint centre is exactly **(x, z) = (0, 0)** in the exported GLB.
- Flat-shaded, palette-only Principled materials, low-poly, no textures. Triangle budget **500 per prop/NPC**, **1500 for the assembled `dungeon_cell_interior`**.
- No names duplicate the 141 GLBs that existed before wave 3.

## Verification summary

- `python3 scripts/verify_models.py`: **171 GLBs, 171 passed, 0 failed**, 40102 triangles total (was 141 GLBs / 33468 triangles before wave 3).
- `python3 scripts/check_metrics.py`: all invariants hold (player 1.55 u, house within 2-4 u, every base Y ~= 0, budgets respected).

## Hero interior composition

| Interior | Footprint (u) | Height (u) | x1.55 player | Tris | Composition |
|---|---:|---:|---:|---:|---|
| `dungeon_cell_interior` | 3.18 x 3.208 | 2.5 | 1.61x | 808 | 3x3 stone floor, eight 1 u wall segments on the ±1.5 grid lines (3 courses each), 0.9x2.0 door, barred window at the 1.1 u sill, hanging chain, stone coffer, torch and bone scatter |

The cell uses the same 1 u grid convention as the earlier kit: wall segments sit on the grid lines and tile centres are the integer cell centres. Its selective bevel (floor slab and coffer lid), weighted normals and smart UV pack follow the game-asset-modeling finishing path used by the wave-2 interiors.

## Reproduce

```bash
~/.local/blender/blender -b --python scripts/blender/gen_models_v3.py
python3 scripts/verify_models.py
python3 scripts/check_metrics.py
python3 scripts/build_models_v3_metrics.py
```
