# Starfall - Model wave 4 metrics

Generated by `python3 scripts/build_models_v4_metrics.py` from `assets/models/expansion_models_v4.json`, the per-asset measurements written by `scripts/blender/gen_models_v4.py` after each GLB export. Numbers are cross-checked against `assets/models/metrics.json`.

## Scale contract

- **1 unit = 1 tile = 1 metre.** Blender is Z-up; exported glTF is Y-up. The tables give **W x D x H** in glTF axes (X footprint x Z footprint x Y height).
- Player reference: **1.55 u** (`player.glb` measures 1.55 u). Every ratio is `measured height / 1.55`.
- Storey height **2.5 u**; doors **0.9 x 2.0 u**; grid pitch **1 u**. `dungeon_treasury_interior` is 2.52 u tall (bevelled capital) and `barred_door` is 2.08 u.
- Every asset's lowest point is exactly **y = 0** and its footprint centre is exactly **(x, z) = (0, 0)** in the exported GLB.
- Flat-shaded, palette-only Principled materials, low-poly, no textures. Triangle budget **500 per prop/NPC/creature**, **1500 for the assembled `dungeon_treasury_interior`**.
- No names duplicate the 171 GLBs that existed before wave 4.
