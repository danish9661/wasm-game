# Starfall - Expansion metrics

Generated by `python3 scripts/build_expansion_metrics.py` from the exported GLBs. Measurements are read from `assets/models/expansion_<family>.json` (written by the Blender generators after export) and cross-checked against `assets/models/metrics.json`.

## Scale contract

- **1 unit = 1 tile = 1 metre.** Blender is Z-up; exported glTF is Y-up. The tables give **W x D x H** in glTF axes (X footprint x Z footprint x Y height).
- Player reference: **1.55 u** (`player.glb` measures 1.55 u). Every ratio is `measured height / 1.55`.
- Storey height **2.5 u**; doors **0.9 x 2.0 u**; windows **0.8 x 0.9 u** raised to a **1.1 u** sill; grid pitch **1 u**.
- Every asset's lowest point is exactly **y = 0** and its footprint centre is exactly **(x, z) = (0, 0)** in the exported GLB.
- Flat shading, palette-only Principled materials, low-poly, no textures. Triangle budget 500 per prop/piece, 1500 for the assembled interiors.

## Verification summary

- `python3 scripts/verify_models.py`: **141 GLBs, 141 passed, 0 failed**, 31506 triangles total.
- `python3 scripts/check_metrics.py`: all invariants hold (player ~1.55 u, house 2-4 u, every base Y ~= 0, budgets respected).
- Hero engine reviews: Babylon (`tools/review/shoot.mjs` in the game-asset-modeling skill) rendered front / three-quarter / eye / iso / iso_context for all four heroes with **0 console errors**; sheets are in `assets/review/<id>.png`.
- Fresh-eyes critic: three review/fix rounds. Final verdict - `blacksmith_hall_interior` and `temple_hall_interior` CLEAN; `mangrove` and `npc_forest_warden` MINORS ONLY. The only remaining note is that the harness's fixed ~40 m `iso_context` frame renders standalone props ~25 px tall; this is review framing, not a model defect (the assets are correct at 1 u = 1 m).

## Kit grid snapping

| Piece | Snap rule |
|---|---|
| `kit_floor` | Exactly one 1x1 tile; tile centres at integer (x, z); floor top = 0.1 u. |
| `kit_wall_wood`, `kit_wall_stone` | One 1 u grid edge of frontage, 0.15 / 0.18 u thick centred on the boundary line, 2.5 u tall; rotate 90 degrees for edges running along Z. |
| `kit_door` | 0.9 u wide (0.05 u gap each side) x 2.0 u tall, centred on X; add a 0.5 u transom to fill the remaining storey height. |
| `kit_window` | 0.8 x 0.9 u; base at 0, raise in Y by 1.1 u so the opening spans 1.1-2.0 u inside a 2.5 u wall. Use the cut-out wall segments `build_wall_wood_window` / `build_wall_stone_window` (in the kit generator) for a real opening instead of burying the window in a solid wall. |
| `kit_stairs` | 1 u wide, six 0.25 u treads over a 1.5 u run, rising 1.5 u to a half-level. |
| `kit_roof_gable` | One 1x1 roof cell; ridge runs along Z (Blender Y) and repeats cell-to-cell; 0.6 u rise. |
| `kit_pillar` | 0.3 sq, 2.5 u tall = one storey; place on grid intersections. |

Wall segments sit on the grid lines: a 5-tile span uses integer centres -2..2, a 4-tile span uses half-integer centres -1.5..1.5. Tile centres are the integer cell centres of the footprint.

## Reproduce

```bash
~/.local/blender/blender -b --python scripts/blender/gen_biome_props.py
~/.local/blender/blender -b --python scripts/blender/gen_npc_variants.py
~/.local/blender/blender -b --python scripts/blender/gen_kit_expansion.py
python3 scripts/verify_models.py
python3 scripts/check_metrics.py
python3 scripts/build_expansion_metrics.py
```

Hero briefs live in `assets/src/<category>/<id>/brief.json`; their style contract is `docs/ART_DIRECTION.md` and `assets/spec.json`.
