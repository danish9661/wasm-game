# Starfall - Model wave 5 metrics

Generated by `python3 scripts/build_models_v5_metrics.py` from `assets/models/expansion_models_v5.json`, the per-asset measurements written by `scripts/blender/gen_models_v5.py` after each GLB export. Numbers are cross-checked against `assets/models/metrics.json`.

## Scale contract

- **1 unit = 1 tile = 1 metre.** Blender is Z-up; exported glTF is Y-up. The tables give **W x D x H** in glTF axes (X footprint x Z footprint x Y height).
- Player reference: **1.55 u** (`player.glb` measures 1.55 u). Every ratio is `measured height / 1.55`.
- Storey height **2.5 u**; doors **0.9 x 2.0 u**; windows raised to a **1.1 u** sill; grid pitch **1 u**. All three hero interiors measure exactly **2.50 u** tall.
- Every asset's lowest point is exactly **y = 0** and its footprint centre is exactly **(x, z) = (0, 0)** in the exported GLB.
- Flat-shaded, palette-only Principled materials, low-poly, no textures. Triangle budget **500 per prop/NPC/enemy**, **1500 for the assembled interiors**.
- No names duplicate the 223 GLBs that existed before wave 5.
